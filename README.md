# Meta Ad Performance Dashboard

# 📊 Project Overview

This project is an interactive **Power BI dashboard** created to analyze and monitor **Meta advertising performance**.

The dashboard provides insights into advertising campaigns based on clicks, impressions, engagement, purchases, demographics, countries, ad types, and time-based trends.

## 🎯 Objectives

* Analyze overall advertising performance
* Understand user engagement with advertisements
* Compare campaign performance
* Analyze clicks based on gender and age
* Identify weekly and hourly click trends
* Analyze advertising performance across countries
* Compare different ad types
* Track important advertising KPIs

## 📌 Key KPIs

* Impressions
* Clicks
* Shares
* Comments
* Purchases
* CTR (Click Through Rate)
* Engagement Rate
* Conversion Rate
* Purchase Rate
* Total Budget
* Average Budget per Campaign

## 📈 Dashboard Analysis

The dashboard includes:

* Clicks by Gender
* Clicks by Age Group
* Weekly Click Trends
* Hourly Click Trends
* Clicks by Country
* Monthly Performance Analysis
* Ad Type Performance
* Campaign Engagement
* Conversion Performance
* Overall Advertising Performance

## 💡 Key Insights

* The dashboard provides an overview of Meta advertising reach, engagement, and conversion performance.
* Click performance can be analyzed across different age groups and genders.
